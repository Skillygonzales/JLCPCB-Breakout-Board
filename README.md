# MPU-6050 Breakout Board

A simple 2-layer PCB designed in **Altium Designer**, following this [YouTube tutorial](https://www.youtube.com/watch?v=Mi9U95MpRXI).

The goal of this project was to get familiar with the PCB design process, from creating schematics to preparing manufacturing files.

### 🔍 [View Interactive PCB (3D, Layout & Schematic)](https://skillygonzales.github.io/JLCPCB-Breakout-Board/)

## What I Learned

**Schematic & PCB Design**
- Creating and managing my own component library
- Drawing clean schematics and placing components
- Configuring design rules based on JLCPCB manufacturing capabilities
- Routing a 2-layer PCB, adding vias and mounting holes
- Running Electrical Rule Check (ERC) and Design Rule Check (DRC)

**Manufacturing Preparation**
- Generating Gerber, BOM and CPL files
- Inspecting manufacturing outputs using Altium CAMtastic

**Git & GitHub**
- Using Git for version control and publishing hardware projects on GitHub
- Hosting an interactive PCB viewer with GitHub Pages
- Automating updates using GitHub Actions whenever changes are pushed

*The GitHub Pages website and Actions workflow were created with AI assistance as part of learning how these tools work.*
